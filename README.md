One image that sums up Sunday 22 November 2026: 30 stories across 7 regions,
every one dated that day and sourced. COP31 collapses with no deal as the EU
rejects the final text; Russia fires 186 drones at Ukraine; Iran claims two
US radars hit in Bahrain. 10 more panels and 17 further stories below the map.

v2 is the feedback revision of v1 (35 stories, 12-0-0, E 98.88%): the judge's
one repeated criticism was "dense layout", so v2 cuts the five weakest ALSO
items and spends the freed space on whitespace instead of more stories.

## Entry

`entry.png` (1024×1024) is the front page. `main.ts` copies it to the
harness output directory, byte for byte, so every run produces the same file.

## Stories

See `SOURCES-v2.md` in the build directory for each story's primary source
and the date audit (wrong-date stories are listed in the DATE CHECK box on
the page itself, excluded from the 30).
